# 📦 OBS Cyber Backup Utility

[🇬🇧 English](README.en.md) · [🇷🇺 Русский](README.md)

**OBS Cyber Backup Utility** — небольшая утилита для Windows для резервного копирования и восстановления настроек **OBS Studio**, сцен, профилей и установленных плагинов.

Программа рассчитана на ситуации, когда нужно сохранить рабочую конфигурацию OBS перед переустановкой Windows, переносом OBS на другой компьютер или изменением системы.

> ⚠️ Перед резервным копированием или восстановлением OBS Studio необходимо закрыть.

## ✨ Возможности

* 📦 Создание резервной копии OBS Studio в ZIP-архив
* 🔄 Восстановление настроек из ZIP-бэкапа
* 🎬 Резервное копирование сцен, профилей и настроек OBS
* 🔌 Сохранение плагинов OBS
* ☑️ Выбор компонентов для резервного копирования
* 🛡️ Проверка созданного ZIP-архива после завершения операции
* 📋 `backup_info.json` с информацией о созданной копии
* 🔍 Проверка выбранного архива перед восстановлением
* 🚫 Проверка, запущен ли OBS Studio перед операцией
* 📊 Отображение прогресса операции
* 🔊 Звуковое уведомление после успешного завершения
* 📝 Автоматическое ведение логов
* 🌐 Интерфейс на русском и английском языках
* 💾 Сохранение настроек программы
* 🖥️ Поддержка запуска как Python-скрипта и подготовленной Windows-сборки

## 🗂️ Что можно сохранить

Программа позволяет отдельно выбрать следующие компоненты:

### AppData

Настройки OBS Studio, сцены и профили пользователя.

```text
%APPDATA%\obs-studio
```

### ProgramData

Плагины OBS Studio:

```text
%PROGRAMDATA%\obs-studio\plugins
```

### Program Files

Системно установленные плагины OBS Studio:

```text
C:\Program Files\obs-studio\obs-plugins
```

Таким образом, можно сделать как полный бэкап OBS, так и сохранить только необходимые компоненты.

## 📦 Формат резервной копии

Резервная копия создаётся в формате:

```text
ZIP
```

В архив дополнительно помещается файл:

```text
backup_info.json
```

В нём сохраняется информация о версии утилиты, времени создания резервной копии, количестве файлов и выбранных компонентах.

Пример:

```json
{
    "app": "OBS Cyber Backup Utility",
    "version": "1.1.0",
    "created": "2026-09-29 14:00:00",
    "total_files": 123,
    "appdata_obs": true,
    "programdata_plugins": true,
    "programfiles_plugins": true
}
```

## 🔐 Проверка резервной копии

После создания ZIP-архива программа выполняет проверку содержимого архива.

Если архив повреждён, операция считается неуспешной.

При восстановлении выбранный файл также проверяется перед началом операции.

## 🚨 Безопасность восстановления

Перед восстановлением программа проверяет:

* запущен ли OBS Studio;
* является ли выбранный файл корректным ZIP-архивом;
* наличие информации о резервной копии;
* целостность содержимого архива;
* возможность записи в необходимые системные каталоги.

Если OBS Studio запущен, программа попросит сначала закрыть его.

Для изменения файлов в системных каталогах Windows может потребоваться запуск программы **от имени администратора**.

## 💻 Перенос OBS на другой компьютер

В программе предусмотрена отдельная функция **«Перенести OBS на другой ПК»**, которая помогает использовать созданную резервную копию для переноса конфигурации.

Общий принцип:

```text
Старый ПК
   │
   ├── OBS Studio
   ├── Сцены
   ├── Профили
   └── Плагины
          │
          ▼
     ZIP Backup
          │
          ▼
      Новый ПК
          │
          └── Restore
```

## 📝 Логи

При работе программы создаётся папка:

```text
logs
```

В ней находятся ежедневные файлы журнала:

```text
app_YYYY-MM-DD.log
```

Логи помогают определить причину ошибки, если резервное копирование или восстановление завершилось неудачно.

## 🔊 Уведомление о завершении

После успешного создания резервной копии программа воспроизводит звуковое уведомление.

Это особенно удобно при большом количестве сцен, профилей и плагинов, когда создание архива может занимать продолжительное время.

## 🖥️ Интерфейс

Программа использует современный тёмный интерфейс на базе **CustomTkinter**.

Основные элементы:

* выбор языка;
* выбор компонентов;
* выбор папки для резервных копий;
* индикатор выполнения;
* создание резервной копии;
* восстановление;
* открытие папки с бэкапами;
* перенос OBS на другой компьютер.

## ⚠️ Важно

Программа работает непосредственно с каталогами OBS Studio.

Перед восстановлением рекомендуется иметь отдельную копию текущих настроек OBS.

Особенно внимательно следует относиться к восстановлению плагинов, поскольку разные версии OBS Studio и сторонних плагинов могут быть несовместимы между собой.

Программа не заменяет стандартные средства резервного копирования Windows и предназначена именно для удобного сохранения конфигурации OBS Studio.
